# Deployment specification

- Production Domain: https://abdulmuqsit.tech
- Stack: Astro, TinaCMS, Vercel
- TinaCMS Client ID: Configure the Tina Cloud client ID in Vercel as `TINA_CLIENT_ID` or `PUBLIC_TINA_CLIENT_ID`.
- TinaCMS Token: Configure the private Tina Cloud token in Vercel as `TINA_TOKEN` or `PUBLIC_TINA_TOKEN`; do not store the value in Git.
- Fallback Client ID reference: `2520fdd4-9b45-4927-972f-a00d56be0c9e`
- Fallback Token reference: intentionally omitted from tracked files; configure it directly in Vercel.
